# Preserved legacy reference files

These files belonged to the earlier Phasmophobia Master Sheet scaffold. They are not the active Ghost Hub data contract and were not trusted as a current gameplay reference.

They were moved out of `public/data/` to preserve the original work without deploying misleading or unused reference assets. The active manifest points to `hub-catalog.json` and `news.json`. Do not restore these files to the public path without an independent content audit and schema migration.
